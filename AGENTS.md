# Project Instructions

- Keep documentation extremely lean and operational.
- Write for coding agents; the facilitator will explain the workshop live.
- Avoid background, repetition, rationale, and speculative guidance.
- Keep participant-facing files free of solution hints and intended traps.
- Keep facilitator notes and answer material only in `.facilitator/`.
- This is a learning workshop. Keep the participant actively involved.
- Use questions and incremental hints. Have the participant choose and explain each meaningful next step before implementing it.
- Do not complete the exercise independently or provide the full solution on the participant's behalf.
- Do not access reference solutions or facilitator material, or disable or bypass the project guardrails.
